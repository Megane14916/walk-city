# 建物効果仕様

## 1. 位置づけ

この文書を建物効果と重複ルールの正本とする。旧文書の「住宅以外は効果なし」「歩数報酬に建物ボーナスを加算しない」「`appliedBonuses` は常に空配列」という記載は廃止する。

価格はこの仕様変更の対象外とし、現行カタログ値を維持する。

## 2. 効果一覧

| code | 建物 | 現行価格 | 効果 |
|---|---|---:|---|
| `small_house` | 住宅（小） | 50 | 人口 +10 |
| `apartment` | 住宅（大） | 200 | 人口 +50 |
| `small_park` | 公園 | 150 | 上下左右に隣接する住宅（小）1軒につき人口 +5、住宅（大）1軒につき人口 +10。1公園あたり最大 +40 |
| `hospital` | 病院 | 600 | 町内の住宅（小）1軒につき人口 +5、住宅（大）1軒につき人口 +10 |
| `commercial` | 商業施設 | 300 | 歩数同期の獲得コインを10%増加 |
| `farm` | 農場 | 100 | 人口 +20 |
| `road` | 道路 | 0 | 上下左右に隣接する土地へ建物を配置可能 |
| `town_hall` | 役所 | 3,000 | 町内の住宅（小）1軒につき人口 +20、住宅（大）1軒につき人口 +30 |
| `factory` | 工場 | 700 | 歩数同期の獲得コインを25%増加 |

## 3. 人口の計算順序

1. `population_flat` を合計する（住宅（小）+10、住宅（大）+50、農場+20）。
2. 公園、役所、病院の住宅数に応じた加算を足す。

式は次のとおり。

```text
人口 = 住宅（小）×10 + 住宅（大）×50 + 農場×20
     + 公園に隣接する住宅（小）×5
     + 公園に隣接する住宅（大）×10
     + 役所がある場合の住宅（小）×20
     + 役所がある場合の住宅（大）×30
     + 病院がある場合の住宅（小）×5
     + 病院がある場合の住宅（大）×10
```

## 4. 重複ルール

- 公園: 同じ住宅が複数の公園に隣接しても効果は1回だけ。斜めは対象外。住宅（大）は2×2の外周が公園に上下左右で接していれば対象とする。1公園が効果を与えられるのは最大4軒で、すべて住宅（大）の場合は合計 +40。
- 病院: 配置数にかかわらず1軒分のみ。病院より前に配置した住宅と、病院より後に配置する住宅の両方を対象とする。
- 役所: 配置数にかかわらず1軒分のみ。役所より前に配置した住宅と、役所より後に配置する住宅の両方を対象とする。
- 商業施設: 最大3軒、合計30%まで。
- 工場: 最大2軒、合計50%まで。
- 商業施設と工場: 合わせて最大50%。適用内訳は商業施設を先に数え、残りの上限へ工場を適用する。
- 通常道路: 既存の通常道路と重なるセルは新規配置せず、課金対象にも含めない。入力線のうち新規セルだけを同一トランザクションで配置する。橋は7セル一括の構造のため、引き続き全セル未占有を必須とする。

## 5. 歩数コインの計算

同期ごとの基本獲得コインに対して合算ボーナス率を掛け、ボーナス適用後の小数点以下を切り捨てる。

```text
獲得コイン = floor(基本獲得コイン × (100 + 合算ボーナス率) / 100)
```

`appliedBonuses` はボーナスが実際に適用された同期で返す。`amount` は上限適用後のパーセントポイントとする。新規獲得コインが0の場合は空配列を返す。
